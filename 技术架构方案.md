## 2. 系统架构设计

### 2.1 分层架构

```
┌─────────────────────────────────────────────────────────────┐
│                    Presentation Layer（展示层）              │
│  Vue 3 + Element Plus + Axios                             │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    API Gateway Layer（网关层）               │
│  路由转发 / 负载均衡 / 限流 / 鉴权                          │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    Application Layer（应用层）               │
│  ┌─────────────┐ ┌─────────────┐ ┌─────────────┐          │
│  │  用户管理   │ │  合同管理   │ │  供应商管理  │          │
│  └─────────────┘ └─────────────┘ └─────────────┘          │
│  ┌─────────────┐ ┌─────────────┐ ┌─────────────┐          │
│  │  物料管理   │ │  定价管理   │ │  集成管理   │          │
│  └─────────────┘ └─────────────┘ └─────────────┘          │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    Domain Layer（领域层）                    │
│  业务实体 / 业务规则 / 领域服务                             │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    Infrastructure Layer（基础设施层）        │
│  数据库访问 / 缓存 / 文件存储 / 第三方服务                   │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 微服务划分

| 服务名称 | 端口 | 职责 | 数据库 |
|---------|------|------|--------|
| srm-gateway | 8080 | API网关，统一入口 | - |
| srm-uaa | 8081 | 用户认证授权 | MySQL |
| srm-system | 8082 | 系统管理（组织架构、字典） | MySQL |
| srm-supplier | 8083 | 供应商管理 | MySQL |
| srm-material | 8084 | 物料管理 | MySQL |
| srm-pricing | 8085 | 定价管理 | MySQL |
| srm-contract | 8086 | 合同管理 | MySQL |
| srm-integration | 8087 | 集成服务（ERP、飞书、企微） | MySQL |
| srm-file | 8088 | 文件服务（图纸、附件） | MinIO |

### 2.3 服务间通信

| 通信方式 | 使用场景 |
|----------|----------|
| REST API | 同步调用（前端→后端、服务→服务） |
| Feign | 服务间同步调用 |
| RabbitMQ | 异步消息（审批通知、数据同步） |
| XXL-Job | 定时任务（ERP同步、数据统计） |

### 4.1 API规范

| 规范 | 说明 |
|------|------|
| RESTful | 使用标准REST风格 |
| 认证方式 | JWT Token |
| 统一响应格式 | `{code, message, data}` |
| 分页格式 | `page, pageSize, total, records` |
| 错误码 | 统一错误码体系 |

## 6. 合同渲染技术方案

### 6.1 异步渲染架构

针对大型合同或批量导出时PDF渲染耗时较长的问题，系统采用**异步渲染架构**，提升用户体验。

**异步渲染流程**

```
用户点击导出PDF → 返回任务ID → RabbitMQ消息队列 → PDF渲染服务 → 上传MinIO → 发送通知 → 用户下载
```

**架构图**

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   前端      │───▶│  API网关    │───▶│  合同服务   │───▶│  RabbitMQ  │
│ (用户点击)  │    │             │    │  创建任务   │    │  消息队列  │
└─────────────┘    └─────────────┘    └─────────────┘    └──────┬──────┘
                                                                  │
                                                                  ▼
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  用户通知   │◀───│  合同服务   │◀───│   MinIO     │◀───│ PDF渲染服务 │
│ (飞书/邮件) │    │  更新状态   │    │  文件存储   │    │ (独立部署)  │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

**技术选型**

| 组件 | 技术 | 说明 |
|------|------|------|
| 消息队列 | RabbitMQ | 解耦前端与渲染服务 |
| 文件存储 | MinIO | PDF文件存储 |
| 通知服务 | 飞书/邮件 | 渲染完成后通知用户 |
| PDF生成 | OpenPDF + Flying Saucer | HTML/CSS转PDF |
| 模板引擎 | Thymeleaf | HTML模板渲染 |

### 6.2 渲染服务设计

**服务特点**

- 独立部署，不影响主系统性能
- 可水平扩展，支持多实例
- 内存限制2GB，防止OOM
- 超时机制（默认60秒）

**任务状态表**

```sql
CREATE TABLE pdf_export_task (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    task_id VARCHAR(50) UNIQUE NOT NULL,
    contract_id BIGINT NOT NULL,
    user_id BIGINT NOT NULL,
    status ENUM('pending', 'processing', 'completed', 'failed') DEFAULT 'pending',
    file_url VARCHAR(500),
    error_message TEXT,
    created_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    completed_time DATETIME,
    FOREIGN KEY (contract_id) REFERENCES contract(id)
);
```

### 6.3 接口设计

**创建渲染任务**

```
POST /api/contract/contracts/{id}/export-pdf-async
Response: { taskId: "xxx", status: "pending" }
```

**查询任务状态**

```
GET /api/contract/export-tasks/{taskId}

```
