# 飞书/企业微信集成配置指南

## 一、飞书（Feishu/Lark）配置

### 1.1 创建飞书应用

1. 访问 [飞书开放平台](https://open.feishu.cn/)
2. 登录并进入「开发者后台」
3. 点击「创建应用」→ 选择「企业自建应用」
4. 填写应用名称和描述
5. 获取以下信息：
   - **App ID**: 应用唯一标识
   - **App Secret**: 应用密钥

### 1.2 配置应用权限

在应用后台 → 「权限管理」中，开通以下权限：

```
- im:message:send_as_bot (发送消息)
- approval:instance:create (创建审批实例)
- approval:instance:get (获取审批实例)
- approval:task:create (创建审批任务)
- approval:task:update (更新审批任务)
```

### 1.3 配置应用事件

在应用后台 → 「添加应用能力」→ 「机器人」

添加事件订阅：
- `approval.instance.create` (审批实例创建)
- `approval.task.create` (审批任务创建)
- `im.message.receive_v1` (接收消息)

### 1.4 填写配置信息

将获取的信息填入 `application-dev.yml` 或环境变量：

```yaml
feishu:
  app-id: cli_xxxxxxxxxxxxxx    # 飞书应用App ID
  app-secret: xxxxxxxxxxxxxx     # 飞书应用App Secret
```

## 二、企业微信（WeChat Work）配置

### 2.1 创建企业微信应用

1. 访问 [企业微信管理后台](https://work.weixin.qq.com/)
2. 登录企业账号
3. 进入「应用管理」→ 「创建应用」
4. 选择应用类型为「自建应用」
5. 填写应用信息并发布
6. 获取以下信息：
   - **AgentId**: 应用AgentId
   - **AgentSecret**: 应用Secret

### 2.2 获取企业ID

在「我的企业」→ 「企业信息」中获取：
- **CorpId**: 企业ID

### 2.3 配置应用权限

在应用详情 → 「企业可信IP」中添加服务器IP

### 2.4 填写配置信息

```yaml
wechat:
  work:
    corp-id: wwxxxxxxxxxxxx      # 企业ID
    agent-id: 1000001            # 应用AgentId
    corp-secret: xxxxxxxxxxxxxx  # 应用Secret
```

## 四、环境变量配置（推荐）

推荐使用环境变量方式配置敏感信息：

### Windows (PowerShell)
```powershell
$env:FEISHU_APP_ID="cli_xxxxxxxxxxxxxx"
$env:FEISHU_APP_SECRET="xxxxxxxxxxxx"
$env:WECHAT_WORK_CORP_ID="wwxxxxxxxxxxxx"
$env:WECHAT_WORK_AGENT_ID="1000001"
$env:WECHAT_WORK_CORP_SECRET="xxxxxxxxxxxx"
```

### Linux/macOS
```bash
export FEISHU_APP_ID="cli_xxxxxxxxxxxxxx"
export FEISHU_APP_SECRET="xxxxxxxxxxxx"
export WECHAT_WORK_CORP_ID="wwxxxxxxxxxxxx"
export WECHAT_WORK_AGENT_ID="1000001"
export WECHAT_WORK_CORP_SECRET="xxxxxxxxxxxx"
```

## 六、测试验证

配置完成后，可以通过以下方式验证：

### 飞书测试
```bash
curl -X POST "https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal" \
  -H "Content-Type: application/json" \
  -d '{"app_id": "your_app_id", "app_secret": "your_app_secret"}'
```

### 企业微信测试
```bash
curl "https://qyapi.weixin.qq.com/cgi-bin/gettoken?corpid=your_corpid&corpsecret=your_corpsecret"
```

## 七、常见问题

### Q: 飞书发送消息失败
A: 检查应用是否开通了「发送消息」权限，且应用已发布

### Q: 企业微信获取token失败
A: 检查CorpId和AgentSecret是否正确，应用是否已启用

### Q: 如何查看API调用日志
A: 查看应用后台的「日志」或系统日志中的`FeishuApiClient`/`WechatWorkApiClient`相关日志
