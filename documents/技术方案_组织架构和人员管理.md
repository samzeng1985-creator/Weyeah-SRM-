## 一、数据库设计

### 1.1 部门表（department）

```sql
CREATE TABLE department (
    id BIGINT AUTO_INCREMENT PRIMARY KEY COMMENT '部门ID',
    code VARCHAR(50) NOT NULL COMMENT '部门编码',
    name VARCHAR(100) NOT NULL COMMENT '部门名称',
    parent_id BIGINT DEFAULT 0 COMMENT '上级部门ID，0表示顶级部门',
    level INT DEFAULT 1 COMMENT '部门层级，1=一级部门',
    leader_id BIGINT COMMENT '部门负责人ID',
    description VARCHAR(500) COMMENT '部门职能描述',
    status VARCHAR(20) DEFAULT 'ACTIVE' COMMENT '状态：ACTIVE=启用，INACTIVE=禁用',
    sort_order INT DEFAULT 0 COMMENT '排序号',
    del_flag INT DEFAULT 0 COMMENT '删除标志：0=未删除，2=已删除',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    created_by VARCHAR(50) COMMENT '创建人',
    updated_by VARCHAR(50) COMMENT '更新人',
    UNIQUE KEY uk_code (code),
    INDEX idx_parent_id (parent_id),
    INDEX idx_status (status)
) COMMENT '部门表';
```

### 1.2 人员表（employee）

```sql
CREATE TABLE employee (
    id BIGINT AUTO_INCREMENT PRIMARY KEY COMMENT '员工ID',
    employee_no VARCHAR(50) NOT NULL COMMENT '员工编号',
    name VARCHAR(100) NOT NULL COMMENT '姓名',
    gender VARCHAR(10) COMMENT '性别：MALE=男，FEMALE=女',
    phone VARCHAR(20) COMMENT '手机号码',
    email VARCHAR(100) COMMENT '电子邮箱',
    department_id BIGINT NOT NULL COMMENT '所属部门ID',
    position VARCHAR(100) COMMENT '职位',
    position_level VARCHAR(20) COMMENT '职级：STAFF=员工，LEADER=主管，MANAGER=经理，DIRECTOR=总监，EXECUTIVE=高管',
    hire_date DATE COMMENT '入职日期',
    leave_date DATE COMMENT '离职日期',
    status VARCHAR(20) DEFAULT 'ACTIVE' COMMENT '状态：ACTIVE=在职，INACTIVE=离职，LEAVE=休假',
    avatar_url VARCHAR(500) COMMENT '头像URL',
    del_flag INT DEFAULT 0 COMMENT '删除标志：0=未删除，2=已删除',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    created_by VARCHAR(50) COMMENT '创建人',
    updated_by VARCHAR(50) COMMENT '更新人',
    UNIQUE KEY uk_employee_no (employee_no),
    INDEX idx_department_id (department_id),
    INDEX idx_status (status)
) COMMENT '员工表';
```

### 1.3 角色表（role）

```sql
CREATE TABLE role (
    id BIGINT AUTO_INCREMENT PRIMARY KEY COMMENT '角色ID',
    code VARCHAR(50) NOT NULL COMMENT '角色编码',
    name VARCHAR(100) NOT NULL COMMENT '角色名称',
    description VARCHAR(500) COMMENT '角色描述',

    is_system INT DEFAULT 0 COMMENT '是否系统预置：0=自定义，1=系统预置',
    sort_order INT DEFAULT 0 COMMENT '排序号',
    del_flag INT DEFAULT 0 COMMENT '删除标志：0=未删除，2=已删除',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    created_by VARCHAR(50) COMMENT '创建人',
    updated_by VARCHAR(50) COMMENT '更新人',
    UNIQUE KEY uk_code (code),
    INDEX idx_status (status)
) COMMENT '角色表';
```

### 1.4 权限表（permission）

```sql
CREATE TABLE permission (
    id BIGINT AUTO_INCREMENT PRIMARY KEY COMMENT '权限ID',
    code VARCHAR(100) NOT NULL COMMENT '权限编码',
    name VARCHAR(100) NOT NULL COMMENT '权限名称',
    module VARCHAR(50) COMMENT '所属模块',
    type VARCHAR(20) DEFAULT 'BUTTON' COMMENT '类型：MODULE=模块，MENU=菜单，BUTTON=按钮',
    parent_id BIGINT DEFAULT 0 COMMENT '上级权限ID，0表示顶级',
    path VARCHAR(200) COMMENT '路由路径',
    icon VARCHAR(100) COMMENT '图标',
    sort_order INT DEFAULT 0 COMMENT '排序号',
    status VARCHAR(20) DEFAULT 'ACTIVE' COMMENT '状态：ACTIVE=启用，INACTIVE=禁用',
    del_flag INT DEFAULT 0 COMMENT '删除标志：0=未删除，2=已删除',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    UNIQUE KEY uk_code (code),
    INDEX idx_parent_id (parent_id),
    INDEX idx_module (module)
) COMMENT '权限表';
```

### 1.5 角色权限关联表（role_permission）

```sql
CREATE TABLE role_permission (
    id BIGINT AUTO_INCREMENT PRIMARY KEY COMMENT '主键ID',
    role_id BIGINT NOT NULL COMMENT '角色ID',
    permission_id BIGINT NOT NULL COMMENT '权限ID',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    UNIQUE KEY uk_role_permission (role_id, permission_id),
    INDEX idx_role_id (role_id),
    INDEX idx_permission_id (permission_id)
) COMMENT '角色权限关联表';
```

### 1.6 用户角色关联表（user_role）

```sql
CREATE TABLE user_role (
    id BIGINT AUTO_INCREMENT PRIMARY KEY COMMENT '主键ID',
    user_id BIGINT NOT NULL COMMENT '用户ID（关联org_user表）',
    role_id BIGINT NOT NULL COMMENT '角色ID',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    UNIQUE KEY uk_user_role (user_id, role_id),
    INDEX idx_user_id (user_id),
    INDEX idx_role_id (role_id)
) COMMENT '用户角色关联表';
```

## 四、业务规则

### 4.1 部门管理规则

1. **编码规则**：`DEPT` + 4位流水号（如 DEPT0001）
2. **层级限制**：最多支持4级部门架构
3. **删除限制**：
   - 有下级部门的部门不可删除
   - 有员工的部门不可删除
4. **唯一性校验**：部门编码不可重复

### 4.2 人员管理规则

1. **编码规则**：`EMP` + 6位流水号（如 EMP000001）
2. **账号管理**：员工创建后自动生成登录账号（邮箱前缀）
3. **离职管理**：
   - 离职后员工状态变为 `INACTIVE`
   - 离职人员自动禁用系统账号
   - 离职人员不可登录系统
4. **唯一性校验**：员工编号不可重复

### 4.3 角色权限规则

1. **预置角色**：系统管理员不可删除
2. **权限变更**：角色权限变更后实时生效
3. **删除限制**：已有用户绑定的角色不可删除
